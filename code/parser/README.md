# Парсер интернет-магазина → отчёт Excel

Концепт для портфолио. Для примера используется books.toscrape.com — учебный магазин,
созданный специально для тренировки парсинга. Под другой сайт меняются адрес и CSS-селекторы
в `parser.py` (функции `product_links` и `parse_item`).

## Что делает

- Обходит все страницы каталога и собирает ссылки на товары.
- Загружает карточки в 8 потоков: название, категория, цена, рейтинг, остаток на складе, артикул.
- Повторяет запрос при сбоях сайта (до 4 раз с паузой), сломанные карточки пробует ещё раз в конце,
  всё записывает в `parser.log`. Одна ошибка не останавливает весь сбор.
- Чистит данные: заглушки вместо категории («Default», «Add a comment») объединяет в «Без категории».
- Строит отчёт Excel из трёх листов:
  - **Товары** — весь каталог со ссылками, фильтрами, цветовой шкалой цен, рейтингом звёздами
    и остатком полосками;
  - **Сводка** — ключевые цифры, таблица по категориям и диаграмма топ-15;
  - **Лучшее** — товары с оценкой 5★ от самых доступных.

Результат реального запуска: 1000 товаров, 49 категорий, 45 секунд, 0 ошибок — файл
`Пример результата.xlsx` в этой папке.

## Запуск

```
pip install -r requirements.txt
python parser.py                     # весь каталог
python parser.py --limit 100         # быстрая проверка на 100 товарах
python parser.py --out отчёт.xlsx --threads 8
```

## Что можно добавить под задачу

Запуск по расписанию, сравнение цен с прошлым запуском (что подорожало/подешевело),
