# Telegram-бот онлайн-записи (барбершоп «Щетина»)

Концепт для портфолио: салон вымышленный, но бот рабочий — достаточно вставить токен.

## Что умеет

- Запись в 5 шагов: услуга → мастер (или «любой свободный») → день → свободное время → имя и телефон.
- Показывает только реально свободное время: учитывает длительность услуги, чужие записи,
  часы работы и не даёт записаться «на прошлое» или раньше чем через 30 минут.
- Защита от двойной записи: если время заняли, пока клиент думал, — бот предложит другое.
- Помнит постоянных клиентов: при повторной записи не спрашивает имя и телефон.
- «Мои записи» — список будущих визитов с отменой в одно нажатие.
- Напоминание клиенту за 2 часа до визита (переживает перезапуск бота).
- Уведомления администратору о новых записях и отменах, команда `/today` — записи на сегодня.
- Кнопка «Отправить мой номер», проверка имени и телефона, кнопки «Назад» на каждом шаге.

## Запуск

1. Установите Python 3.11 или новее.
2. В папке бота: `pip install -r requirements.txt`
3. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
4. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от BotFather;
   - `ADMIN_ID` — ваш числовой id (узнать можно у @userinfobot), сюда придут уведомления.
5. `python bot.py`

## Как поменять под свой бизнес

Всё в файле `data.py`: название, адрес, часы работы, услуги с ценами и длительностью, мастера,
шаг сетки времени и на сколько дней вперёд открыта запись.

## Проверка без интернета

`python tests/test_flow.py` — тест проходит за клиента весь путь (35 проверок): запись, повторная
запись, отмена, гонка за одно время, «любой мастер», устаревшие кнопки, напоминание, команды админа.
Токен для этого не нужен: сервер Telegram подменяется имитацией (`tests/fake_telegram.py`).

## Файлы

| Файл | Что внутри |
|---|---|
| `bot.py` | логика диалога, кнопки, напоминания |
| `data.py` | услуги, мастера, расчёт свободного времени |
| `db.py` | хранение записей в SQLite (отдельный сервер БД не нужен) |
| `config.py` | чтение настроек из `.env` |
| `tests/` | автотест и имитация Telegram |

Для работы 24/7 бота размещают на VPS (от ~200 ₽/мес) и запускают как службу (systemd / pm2).
