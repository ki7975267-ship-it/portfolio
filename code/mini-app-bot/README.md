# Telegram Mini App «Тесто» — доставка пиццы

Концепт для портфолио: пиццерия вымышленная, приложение и бот рабочие.

## Что внутри

- `index.html` + `menu.js` — само мини-приложение (HTML/CSS/JS, без сборки и фреймворков):
  меню по категориям, корзина, «Добавить к заказу?», доставка или самовывоз, время, комментарий,
  промокод, бесплатная доставка от суммы, минимальный заказ, экран «Заказ принят».
- Работает через Telegram WebApp API: нативная главная кнопка и кнопка «Назад», вибрация при нажатиях,
  имя пользователя из Telegram, светлая/тёмная тема берётся из настроек Telegram.
- Открытое в обычном браузере, приложение показывает свою кнопку внизу — удобно для показа клиенту.
  Тёмная тема в браузере: `index.html?theme=dark`.
- `bot.py` — бот, который открывает приложение кнопкой и принимает заказы. **Цены пересчитывает сам**
  по тому же `menu.js`, поэтому подменить сумму из браузера нельзя. Присылает клиенту подтверждение,
  а администратору — заказ с адресом.

## Запуск

1. Разместите `index.html` и `menu.js` на любом хостинге с HTTPS (GitHub Pages, Netlify, свой сервер).
2. Создайте бота у @BotFather, скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN`,
   `WEBAPP_URL` (адрес из п. 1) и `ADMIN_ID`.
3. `pip install -r requirements.txt` и `python bot.py`.

Меню, цены, промокоды, сумма бесплатной доставки и адрес самовывоза меняются в одном файле — `menu.js`.

## Проверка

- `python tests/test_bot.py` — 12 проверок бота без интернета: заказ, пересчёт цен, промокод,
  платная/бесплатная доставка, подмена суммы, несуществующий товар, заказ без адреса, минимальная сумма.
- Само приложение проверено кликами в браузере (17 сценариев: корзина, докупка, промокод, адрес,
  минимальный заказ, самовывоз, тёмная тема).
